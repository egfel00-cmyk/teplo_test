- `gen.html` + `make.cjs` + `cases.json` — рисуют ЖК-экраны теплосчётчиков (шрифт DSEG7/DSEG14 из npm-пакета `dseg`,
  положить .woff2 рядом) с наклоном, размытием, бликом и «тенями» сегментов → jpg.
- Прогнать движок `web/ocr/engine.js` в Chromium (Playwright, файлы подменять через `page.route`, без локального сервера),
  сохранить строки → `tests/fixtures/ocr_synth.json` → `node tests/ocrparse.test.js`.
- Реальные фото людей в репозиторий не класть.
- `node tests/ocr-lab/heat.cjs [heat_err.json|cases.json] [фильтр]` — всё сразу: рисует экраны в `out/`, гонит движок и разбор
  `ocrparse.js` (модель по умолчанию sharky774, `"model": null` — без модели), итог «N/M», строки → /tmp/ocr_heat.json
  (из них — фикстуры). `NOMAKE=1` — не перерисовывать. Шрифты: `npm i dseg` → `DSEG7Classic-Bold.woff2`,
  `DSEG14Classic-Bold.woff2` рядом с gen.html (в git не идут).
- `heat_err.json` — экран кода ошибки: «E-------» (Sharky: E и 7 прочерков = ошибок нет) с бликом, наклоном, размытием,
  издалека, без модели; коды E-3, E-9, C-1, E-7. На 02.11.2026 — 16/16, основной `cases.json` — 13/13.
  Как движок пишет «E-------»: «ERR» / «E--», «88888888» / «Ｅ-—————-», «8888» / «E---», кусками «ER» + «一1».

## Водомеры (барабан)
- `water.html` + `water_cases.json` + `water.cjs` — рисуют водомеры в стиле Novator/КСМ: чёрные ролики с белыми цифрами,
  красные дробные (или красные цифры на белом), кольцо красное/синее, тёмные промежутки, тень окна, запотевание, вспышка,
  полуповорот последнего ролика, вверх ногами, 6 чёрных роликов → `out/*.jpg` (не в git).
- `node tests/ocr-lab/run.cjs [cases.json] [фильтр]` — движок + `TeploWater.fromOcr`, итог «N/M», строки → /tmp/ocr_water.json.
  Свои фото: `IMG_DIR=/путь node run.cjs my.local.json` (`[{id, file, truth, prev?}]`, файл `*.local.json` в git не попадает).
- `RAD=2 node tests/ocr-lab/dbg.cjs <папка> a.jpg …` — маска поиска окна (тёмное серым, красное красным, блоки рамками) → /tmp/dbg_*.png.
- На 02.11.2026: рисунки 22/25 (мимо — полуповорот без прошлого и вспышка), фото владельца 4/5 (КСМ 175, MASTER 458,
  UA-TRADE 197 ×2; мимо — снимок двух счётчиков издалека с бликом на «00»).
- `water_pair.json` — несколько водомеров в кадре (`pair`) и блик стекла на ведущих роликах (`lead: N`):
  `node water.cjs water_pair.json && node run.cjs water_pair.json` (случаи с `meters` читаются с `{all:true}` и
  раскладываются `TeploWater.assign`, truth — `{h1, c1}`, прошлые — `prevs`). На 02.11.2026 — 5/5; основной набор 23/25.

## Ролик между цифрами (полуповорот)
- Движок (`halfFix` в engine.js) разбирает окно на ролики по светлому: полоса окна по высоте (где много тёмного), светлое —
  ярче окрестности, промежутки и кромки рамки прочь, наклон ряда выправляется. Ролик на переходе — два куска с пустой полосой
  (низ цифры d сверху, верх d+1 снизу) или один кусок у края окна. Пару (d, d+1) узнаём по шаблонам: цифры соседних роликов
  (тот же шрифт) и цифры шрифтов браузера (`TPL_FONTS`: узкий, Arial/Helvetica, DIN), строгий Dice, сжатие у краёв окна.
  Принимаем при sc ≥ 0,5 и отрыве от второй пары ≥ 0,03, иначе «?» (человек допишет): на чужом шрифте так нет уверенных ошибок.
  Результат — `drums[].half: [{i, d, sc, margin, rank}]`, `TeploWater.fromDrum` → `half: true, pair: [[d, d+1]]`.
- `water.html`: `curve` — ролик-цилиндр (цифры у краёв окна сжаты), `halfs: [...]` — перенос (239→240: два ролика на переходе),
  `font` — другой шрифт цифр.
- `water_half.json` — 17 случаев (все пары 0|1…9|0, тёмные/светлые окна, цилиндр, наклон, издалека, перенос, с прошлым и без).
  На 02.11.2026 — 17/17 (было 5/17). `water_half_fonts.json` — 12 случаев шрифтами Liberation/FreeSans/Inter/Mono/Carlito:
  9/12, промахи — «?», не чужая цифра. Как на телефоне (нет шрифта лаборатории):
  `TPL_FONTS='["\"Liberation Sans\", sans-serif"]' node run.cjs water_half.json` — 17/17, шрифты — 8/12.
- `node half.cjs water_half.json` — что узнано по каждому случаю (пара, sc, margin, rank) — для подбора порогов;
  `node strip.cjs h3.jpg` — полоса окна и маска светлого → /tmp/strip_*.png.
- Основной набор теперь 25/25 (w_half и r_half читаются), пары 5/5, экраны тепла 16/16 и 13/13.
