# Теплосервис — карта навигации (скил `navigation-map`, режим overview)

Единственный источник экранов и переходов. Экран без выхода — ошибка (гейт `deadends`). Листы и тосты, которые только возвращают на родителя, — состояния, а не экраны.

## Оболочка
Мобильный: нижняя панель **Головна · Історія · Довідка · Налаштування**. Десктоп ≥ 960 px: та же навигация слева. В мастере (S05–S06) панель скрыта, есть «✕ Закрити» → S01 (черновик сохраняется).

## Состояния (не экраны)
S01: окно `closed_before / open / soon_recommended / late / last_day / closed_after`; «есть черновик»; «на проверке у робота»; «пустая история». S06: `ok / warn / block`. S08: `waiting (таймер) / ready_to_check / accepted / rejected`. S07: «скопировано» (тост у поля).

## Резерв (вне бесплатной части)
Автоотправка (S07 карточка «у розробці»), вход/аккаунт, бот, платёжки, фото-распознавание — по строке на зону, без экранов.
