# Теплосервис — минимальный брендбук (скилы `brandbook-generating` + линза `frontend-design`)

Брендбука не было → минимальный seed: цвета, шрифты, стиль иконок, настроение.

## Ревизия 1 → 2 (почему поменяли)
Первый вариант — тёплый кремовый фон, терракотовый акцент, системный шрифт — это самый частый «сгенерированный» вид страниц, к предмету отношения не имеет. Направление пересобрано **из предмета**: серо-зелёный пластик корпуса теплосчётчика, его ЖК-экран с семисегментными цифрами и маркировка труб — красная подача, синяя обратка.

## Настроение
Прибор у тебя в руке. Спокойный «приборный» интерфейс, где всё тихое и аккуратное, а **одна** вещь запоминается — экран счётчика с семисегментными цифрами. Он показывает ровно то, что человек видит на приборе, и по мере ввода повторяет набранное: сверить «как на экране» можно глазами.

## Цвета
| Токен | HEX | Где |
|---|---|---|
| `housing` | #E9EEEB | фон — пластик корпуса |
| `surface` | #FFFFFF | панели, поля |
| `ink` | #17211E | текст и основные кнопки (белый текст на ink — 15:1) |
| `ink-2` | #4A5652 | вторичный текст (≥ 7:1 на housing) |
| `line` | #CFD7D3 | границы полей, разделители |
| `lcd` | #BCC8A2 / `lcd-ink` #1C2618 / `lcd-off` #AAB78E | экран и сегменты (горящие / погашенные) |
| `supply` | #D04A1D | подача, «тепло» — только температура подачи и знак логотипа |
| `return` | #2F68B0 | обратка — только температура обратки и знак |
| `ok` / `ok-soft` | #1E7B4C / #DFF1E7 | «Прийме», «Прийнято» |
| `warn` / `warn-soft` | #8F5600 / #FBEFD5 | «Перевірте» |
| `bad` / `bad-soft` | #A3142E / #F9E1E5 | «Не прийме», «Не прийнято» (малиновый, отличим от оранжево-красной подачи) |
| `info` / `info-soft` | #2F68B0 / #E2ECF8 | «На перевірці», окно приёма |

Светофор никогда не только цветом: иконка + слово.

## Шрифты
- **IBM Plex Sans** (кириллица) — весь интерфейс: инженерный, но тёплый, с честными цифрами; уместен рядом с прибором. 400 / 500 / 600.
- **IBM Plex Mono** — значения, которые копируют в кабинет ХТМ (точка видна, разряды стоят столбиком).
- Цифры показаний на «экране» — собственные семисегментные SVG, не шрифт.
- Шкала (мобильный): 15 / 17 / 20 / 26 / 34; строка 1.5 для текста, 1.2 для заголовков. Строка текста ≤ 70 знаков. Без капса и надзаголовков.
- На NAS шрифты кладём локально; в прототипе — Google Fonts, запасной — системный стек.

## Иконки
Линейные 1.75 px, скруглённые концы, 24×24, свои SVG: кнопка прибора, копировать, галочка, крестик, часы ожидания, вопрос, стрелка назад, термометр.

## Форма
Экран счётчика — с «рамкой» (bezel) и скруглением 10 px, как окно на корпусе. Поля 10 px, кнопки 12 px. Тени — только у нижней панели навигации на мобильном. Касание ≥ 48 px. Однотипных карточек-плиток нет: списки — строками с разделителями.
