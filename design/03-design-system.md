# Теплосервис — дизайн-система (скилы `design-brief` + `ds-generate`, режим «с нуля», web, mobile-first)

Источник фактов: `02-brandbook.md`. Реализация — CSS-переменные и классы в `web/src/styles.css`; компоненты — функции `ui.*` в `web/src/app.js`. Каждый экран помечен `data-screen`, ключевые элементы — `data-key` (трассировка, скил `screen-traceability`).

## Токены
`--c-*` цвета из брендбука v2 (housing, surface, ink, ink-2, line, lcd*, supply, return, ok/warn/bad/info); `--sp-1…7` = 4, 8, 12, 16, 24, 32, 48 px; `--r-card` 14, `--r-field` 12, `--r-pill` 999; `--fs-s` 15, `--fs-m` 17, `--fs-l` 22, `--fs-xl` 28, `--fs-lcd` 34; `--tap` 48 px.

## Атомы
| Компонент | Состояния |
|---|---|
| Кнопка `btn` (primary / secondary / ghost / danger) | обычная, наведение, фокус (кольцо 3 px), нажата, недоступна, загрузка |
| Поле числа `field-num` (с единицей справа, `inputmode=decimal`) | пусто, ввод, ok (+прирост), warn, block, недоступно |
| Метка-пилюля `pill` (ok / warn / bad / info / neutral) | — |
| Иконка `ico` | 24 / 20 / 16 |
| Ссылка | обычная, посещённая, фокус |

## Молекулы
| Компонент | Назначение |
|---|---|
| `lcd` — экран счётчика (семисегментные SVG-цифры + метка) | показывает, что искать на приборе, и **повторяет введённое по мере набора**; метка в углу (m³) или чередование (ht/ct, On/Eh) |
| `step-head` — «Крок 3 з 8» + прогресс-полоса | ориентир в мастере |
| `press` — «Натисніть кнопку ×2» с иконкой кнопки | действие на приборе |
| `copy-row` — подпись, значение (моно), кнопка «Копіювати» | экран передачи в ХТМ |
| `issue` — строка проверки: иконка уровня, текст, совет, «Виправити» | экран проверки |
| `window-banner` — состояние окна приёма | главная, проверка |
| `status-chip` — статус показания | история, главная |
| `meter-card` — картинка, модель, метка «перевірено/уточнюється» | выбор счётчика |

## Организмы и шаблоны
- `app-shell`: шапка (знак — две трубы, красная и синяя; слово «Теплосервіс»; без переключателя мови — язык по браузеру), контент, нижняя навигация на мобильном (Головна · Історія · Довідка · Налаштування), боковая на десктопе ≥ 960 px. В мастере навигация скрыта, есть «Закрити» (черновик сохраняется).
- `wizard`: step-head, инструкция (press + lcd--hint), поле(я), подсказка, кнопки «Назад» / «Далі». На десктопе — две колонки: слева иллюстрация и инструкция, справа поля.
- `verdict-panel`: большой светофор + список `issue` + действия.
- `handover`: список `copy-row` в порядке формы ХТМ, «Скопіювати все», ссылка на кабинет, «Я зберіг у кабінеті».

## Брейкпоинты
360–599 мобильный (одна колонка), 600–959 планшет (шире поля, 2 колонки в истории), ≥ 960 десктоп (боковая навигация, мастер в 2 колонки, max-width контента 1080).

## Доступность
Контраст текста ≥ 4.5:1 (основной ≥ 7:1), фокус виден, все поля с `<label>`, ошибки связаны `aria-describedby`, статусы озвучиваются `aria-live="polite"`, светофор — иконка + слово, анимации отключаются при `prefers-reduced-motion`.
