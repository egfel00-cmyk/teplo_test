# Теплосервис — справочник ошибок и учёт повирки (v2, 01.11.2026)

## 1. Что делаем
- **Справочник ошибок** на сайте и в боте: по модели и коду — что значит, считает ли счётчик тепло во время ошибки, что делать, кого звать.
- **Мониторинг ошибок** («Плюс»): код или рост Eh в показании (ручном или M-Bus) → уведомление с объяснением и кнопкой заявки установщику; история ошибок.
- **Учёт повирки** («Плюс»): даты, свидетельства, срок, напоминания за 90/30/7 дней, заказ у установщика, отметка «свидетельство передано в ХТМ».
- **Бесплатно:** публичный справочник кодов (канал привлечения) и **одно уведомление «срок повирки истекает»** — рекомендация анализа аналогов: без него показания могут не принять, а это противоречит принципу «бесплатно всё, без чего нельзя правильно передать показания». Окончательное решение — за владельцем проекта.

## 2. Как выглядит
- **Бот:** пишешь «E-7»/«F0» или фото экрана → ответ по модели твоего счётчика, кнопки «Заявка установщику» / «Прошло». В мастере ввода на шаге «код ошибки» — сразу объяснение. Напоминания о повирке; после повирки — «загрузите свидетельство» и чек-лист «как передать в ХТМ».
- **Сайт:** публичные страницы «Коды ошибок <модель>»; карточка счётчика: статус повирки (зелёный / скоро / просрочено), история повирок со сканами, история ошибок, график Eh.

## 3. Правила повирки
- Межповерочный интервал для теплосчётчиков и водомеров — **4 года** (наказ Мінекономрозвитку № 1747 от 13.10.2016; разъяснение Держпродспоживслужби).
- Периодическую повирку оплачивает владелец (Закон «Про комерційний облік теплової енергії та водопостачання», с 02.08.2017).
- **Военное положение:** постановление КМУ № 412, на котором держалось объявление ХТМ от 06.06.2022 «принимаем показания счётчиков с истёкшей повиркой на время военного положения + 3 месяца», **утратило силу**; с 04.06.2023 действует **ПКМУ № 440**. По нему срок, в течение которого прошлая повирка считается действующей, зависит от территории: для территорий активных и возможных боевых действий — 6 месяцев после их окончания; для остальной Украины — сдать на повирку в течение 3 месяцев после окончания отопительного периода (по новости Держпродспоживслужби; текст постановления не читали). **Категорию Харьковской громады и актуальность объявления ХТМ выяснить.** До этого сервис не обещает, что просроченный счётчик примут.
- Киев для сравнения: показания неповеренного счётчика не принимают; отопление начисляют по объёму прошлого сезона с поправкой на домовой счётчик, ГВ — по среднему за 12 месяцев; кабинеты КТЕ/ЦКС сами предупреждают о сроке повирки.
- ХТМ: по договору исполнитель обязан «контролювати дотримання установлених міжповірочних інтервалів» (п. 43(12)); повирку и ремонт делает сам — 050 345 14 20; снятие архива — 050 670 13 45; **как передать свидетельство — не описано**, поддержка сайта документы не принимает → в сервисе чек-лист вариантов (районная филия, телефон, email) вместо кнопки «передано».
- Цены OTOS (Харьков): повирка теплосчётчика **1800 грн**, замена батареи 600/900 грн, демонтаж+монтаж 500 грн.
- **Счётчик пользователя (Sharky 774):** по часам On работает примерно с 09.12.2021, на корпусе M23. Если отсчёт от 2021 — 4 года вышли в 12.2025. Проверить паспорт/свидетельство.

## 4. Справочник кодов (стартовый набор)
### Diehl SHARKY 774 (руководство Diehl)
Сообщение исчезает, когда причина устранена; ошибки > 6 мин без перерыва пишутся в память.
| Код | Значение | Что делать |
|---|---|---|
| C-1 | Ошибка базовых параметров flash/RAM | Замена счётчика → установщик |
| E-1 | Ошибка температуры: вне −19,9…190 °C, КЗ/обрыв датчика | Установщик |
| E-3 | Датчики подачи/обратки перепутаны | Установщик |
| E-4 | Аппаратная ошибка УЗ-измерения | Установщик |
| E-5 | Слишком частое чтение — M-Bus временно недоступен | Подождать; реже опрашивать |
| E-6 | Неверное направление потока | Установщик |
| E-7 | Нет УЗ-сигнала, воздух в измерительном участке | Стравить воздух / ОСББ / установщик |
| E-9 | Заканчивается батарея | Замена батареи (часто с повиркой) |

### Diehl SHARKY 775 / Danfoss SONOMETER 1100 — те же + E-A…E-d (утечки).
### Landis+Gyr ULTRAHEAT T330 / T230
| Код | Значение | Что делать |
|---|---|---|
| F0 | Нет расхода — воздух | Стравить воздух |
| F1 / F2 | Обрыв датчика подачи / обратки | Установщик |
| F3 | Электроника температур | Установщик |
| F4 | Батарея разряжена | Замена батареи |
| F5 / F6 | КЗ датчика подачи / обратки | Установщик |
| F7 | Внутренняя память | Установщик |
| F8 | F1–F6 > 8 ч или вмешательство; сброс только сервисом | Сервис |
| F9 | Электроника | Установщик |
| FL nEG / DIFF nEG | Обратный поток / отрицательная ΔT | Установщик |

### Kamstrup MULTICAL 302 — «INFO», коды 1, 2, 4, 8, 16, 32, 128 суммируются (раскладывать).
### Apator ELF — «Er NN» (суммы), «Lou BAt».
### Axioma QALCOSONIC (по E4) — «Er: 0000»: 1 батарея; 2/4 ΔT; 8 аппаратная; датчики 8 обрыв / C КЗ; расходомер 1 нет сигнала, 2 обратный поток.
### Engelmann SensoStar — H80 батарея, H40 сброс, H20 электроника, H10 расход, H01–H08 датчики.
### Danfoss SonoSafe 10 — E01–E18, E32 (дополнить по документации).
### TRUST, Itron, GROSS/METRON, BMeters — пополнять через мастер новой модели.

## 5. Таблицы
```sql
CREATE TABLE error_codes (
  id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  family VARCHAR(40) NOT NULL, meter_model_id INT UNSIGNED NULL, code VARCHAR(20) NOT NULL,
  severity ENUM('info','warning','critical') NOT NULL, energy_counted ENUM('yes','no','unknown') DEFAULT 'unknown',
  bitmask TINYINT(1) DEFAULT 0,
  title_uk VARCHAR(160), title_ru VARCHAR(160), meaning_uk TEXT, meaning_ru TEXT, action_uk TEXT, action_ru TEXT,
  who ENUM('self','installer','osbb','htm') NOT NULL, source_url VARCHAR(255), UNIQUE (family, code)
);
CREATE TABLE meter_errors (
  id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, meter_id INT UNSIGNED NOT NULL, code VARCHAR(20) NOT NULL,
  first_seen_at DATETIME NOT NULL, last_seen_at DATETIME NOT NULL, resolved_at DATETIME NULL,
  hours_err_at_start INT UNSIGNED NULL, hours_err_at_end INT UNSIGNED NULL,
  source ENUM('reading','mbus','user_report') NOT NULL, notified_at DATETIME NULL
);
CREATE TABLE meter_verifications (
  id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY, meter_id INT UNSIGNED NOT NULL,
  verified_on DATE NOT NULL, valid_until DATE NOT NULL, result ENUM('fit','unfit') NOT NULL,
  certificate_no VARCHAR(60) NULL, performed_by_partner_id INT UNSIGNED NULL, performed_by_text VARCHAR(160) NULL,
  doc_path VARCHAR(255) NULL, sent_to_provider_at DATETIME NULL, sent_channel VARCHAR(60) NULL,
  battery_replaced TINYINT(1) DEFAULT 0, note VARCHAR(255) NULL
);
```
