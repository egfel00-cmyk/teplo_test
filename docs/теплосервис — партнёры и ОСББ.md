# Теплосервис — партнёры (установщики) и ОСББ (v2, 01.11.2026)

## 1. Установщики и метрологи
**Кто в Харькове (проверено):**
- **OTOS** (otos.com.ua, (050) 388-40-20) — ставит и поверяет счётчики в доме пользователя; повирка теплосчётчика 1800 грн, батарея 600/900 грн, демонтаж+монтаж 500 грн. Цифровых инструментов для клиентов нет (договор по email/Viber, оплата QR Приват24). Раньше предлагала проводную M-Bus-сеть с онлайн-доступом владельца и балансодержателя — **сейчас услуга не оказывается**.
- **Сам ХТМ** делает повирку и ремонт (050 345 14 20) — и партнёр, и конкурент установщиков.
- **КП «Вода»** — указан в партнёрах на сайте ХТМ (что делает — уточнить).
- **TRUST** («Сервісно-метрологічний центр») — наклейка на счётчике соседа, сам центр поиском **не найден**; не упоминать в материалах, пока не подтвердим.

**Их боль:** звонки «как снять / что значит E-5», забытая повирка → снятие с учёта и потерянный повторный заказ, потерянный контакт с клиентом и бумажный журнал.

**Что даём партнёру:**
1. **QR-наклейка на счётчик и в журнал** «Знімайте показання тут» → бот/сайт с логотипом партнёра, счётчик предзаполнен (модель, номер, единица, дата повирки).
2. **Панель партнёра:** свои клиенты (только с их согласия), сроки повирки и батареи, ошибки, кто не передаёт показания.
3. **Заявки:** «Викликати майстра / замовити повірку»; напоминание за 3 месяца до конца повирки → повторный заказ.
4. Меньше звонков: инструкции и расшифровка ошибок в боте.
5. Опционально white-label.

**Модели дохода (проверить на пилоте):** 10–20 грн за активного клиента за сезон · 300–500 грн/мес за панель · 50–100 грн с заявки · партнёр дарит клиентам сезон «Плюса».
**Почему это канал:** QR висит на счётчике — человек видит его в момент снятия; у установщика сотни–тысячи клиентов.
**Данные:** пользователь — наш клиент; партнёр видит только разрешённое (`data_shares`), отзыв в любой момент; договор с партнёром, данные не продаём.
**Пилот:** OTOS, один сезон бесплатно, дом пр. Перемоги 86а → метрики: подключения, показания вовремя, заявки на повирку.

## 2. ОСББ — после MVP
**Конкуренты/аналоги:** «Компанія ЕнергоСистеми» (Запорожье, rozpodil.askue.net) — единственная найденная платформа, которая явно считает Методику 315, но только со своими LoRaWAN-счётчиками (ТЕПЛОmeter™ 3 300 грн или 55 EUR — противоречиво), без приложения для жильцов и без передачи поставщику. Массовые ОСББ-платформы («Мій Дім Online», ОСББ+, «Моє ОСББ», osbb.work, TQM, PortmoneBilling) — поддержку 315 и цены проверить. Моделей «за квартиру в месяц» в Украине не найдено.
**Позиция:** независимая от вендора железа проверка распределения + статус передачи показаний по квартирам.
**Что даём:** статус передачи по квартирам в окно 5–25 (без цифр, если жилец не разрешил); домовой счётчик (у ХТМ есть /cabinet/house/login — выяснить, что там доступно); сверка распределения (небаланс, МЗК, ФС); объявления через бота; групповая повирка с установщиком.
**Цена (гипотеза):** 3–5 грн/квартира/мес или фикс за дом.

## 3. Таблицы
```sql
CREATE TABLE partners (
  id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY, name VARCHAR(120),
  type ENUM('installer','metrology','osbb','provider') NOT NULL,
  ref_code VARCHAR(20) UNIQUE, branding JSON NULL, terms JSON NULL
);
CREATE TABLE user_partner (user_id INT UNSIGNED PRIMARY KEY, partner_id INT UNSIGNED NOT NULL, joined_at DATETIME NOT NULL);
CREATE TABLE partner_users (
  partner_id INT UNSIGNED NOT NULL, user_id INT UNSIGNED NOT NULL,
  role ENUM('admin','staff','board') NOT NULL, PRIMARY KEY (partner_id, user_id)
);
CREATE TABLE data_shares (
  user_id INT UNSIGNED NOT NULL, partner_id INT UNSIGNED NOT NULL,
  scope SET('meter_info','verification','errors','submit_status','readings','bills') NOT NULL,
  granted_at DATETIME NOT NULL, revoked_at DATETIME NULL, PRIMARY KEY (user_id, partner_id)
);
CREATE TABLE onboarding_codes (
  code CHAR(10) PRIMARY KEY, partner_id INT UNSIGNED NOT NULL,
  meter_model_id INT UNSIGNED NULL, serial_no VARCHAR(40) NULL, energy_unit VARCHAR(5) NULL,
  verification_due DATE NULL, address_hint VARCHAR(255) NULL, claimed_by INT UNSIGNED NULL, claimed_at DATETIME NULL
);
CREATE TABLE service_requests (
  id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY, user_id INT UNSIGNED NOT NULL, meter_id INT UNSIGNED NOT NULL,
  partner_id INT UNSIGNED NOT NULL, type ENUM('verification','battery','repair','install','other') NOT NULL,
  status ENUM('new','accepted','done','canceled') DEFAULT 'new', created_at DATETIME NOT NULL, note VARCHAR(255) NULL
);
```
