# Теплосервис — блок новостей (v2, 01.11.2026)

## 1. Зачем
Новости Харькова, влияющие на тепло и платёжки: тарифы и мораторий, начало/конец сезона, отключения и графики, Методика 315, повирка, абонплата, **изменения договоров ХТМ (сроки приёма показаний)**, плюс вода и свет. Важное — сразу уведомлением, остальное — лентой и дайджестом. Новость превращается в **предложение изменить сервис** (тариф, даты сезона, окно приёма, правила) — только после подтверждения админом.

## 2. Источники (официальные — первыми)
| Источник | Что берём | Как читаем |

| **Страница договоров ХТМ** (info_for_public_contract.php) | новые редакции договоров → **окно приёма показаний**, правила при непередаче | хэш списка PDF и текста; изменение → «пересмотреть `provider_windows`» |

## 3. Как работает
cron (30–60 мин) → загрузка (ETag/кэш) → разбор → фильтр (Харьков + ключевые слова) → склейка дублей (официальный источник первым) → категория и важность (правила; опционально пересказ через Claude API) → лента → уведомления → действия для админа.
Ключевые слова: тариф, Гкал, опалювальний сезон, опалення, теплопостачання, гаряча вода, мораторій, абонплата, Методика 315, повірка, лічильник тепла, ХТМ, ТЕЦ-5, відключення, графік, перерахунок, субсидія, договір, показання.
Категории: тарифы · сезон · отключения · правила начислений · повирка · оплата и субсидии · вода · свет. Важность: высокая (тариф, сезон, отключение в районе, изменение окна приёма), обычная, низкая.

## 4. Где видно
Сайт/Mini App — лента «Новини тепла Харкова» (заголовок, дата, источник, пересказ своими словами, ссылка); бот — важное сразу, недельный дайджест, `/news`; настройки категорий. **Бесплатно для всех.** Плюс публичная страница «Когда и как передавать показания ХТМ» со ссылками на пункты договоров (сроков не находят даже СМИ).

## 5. Новость → действие (подтверждает админ)
| Новость | Предложение |
|---|---|
| Новый тариф / мораторий | черновик в `tariffs` |
| Начало/конец сезона | даты сезона |
| Новая редакция договора ХТМ | пересмотр `provider_windows` и `provider_rules` |
| Методика, повирка | пометка «пересмотреть правила» |
| Отключение в районе | запись в журнал перебоев (с согласия) |

## 6. Правила сбора
Заголовок + пересказ своими словами + ссылка, полный текст не копируем; robots.txt, редкий опрос, честный User-Agent, кэш; официальный источник выше СМИ.

## 7. Таблицы
```sql
CREATE TABLE news_sources (
  id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY, name VARCHAR(120) NOT NULL,
  type ENUM('rss','html','telegram','pdf_list','google_news','page_hash') NOT NULL,
  url VARCHAR(500) NOT NULL, selectors JSON NULL, trust ENUM('official','media','aggregator') NOT NULL,
  poll_minutes SMALLINT DEFAULT 60, enabled TINYINT(1) DEFAULT 1,
  last_polled_at DATETIME NULL, etag VARCHAR(200) NULL, last_modified VARCHAR(100) NULL,
  content_hash CHAR(64) NULL, last_error VARCHAR(255) NULL
);
CREATE TABLE news_items (
  id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, source_id INT UNSIGNED NOT NULL,
  url VARCHAR(700) NOT NULL, url_hash CHAR(64) NOT NULL UNIQUE, title VARCHAR(400) NOT NULL,
  published_at DATETIME NULL, fetched_at DATETIME NOT NULL, excerpt VARCHAR(500) NULL,
  summary_uk TEXT NULL, summary_ru TEXT NULL,
  categories SET('tariff','season','outage','methodology','verification','payments','water','electricity','contract') NULL,
  importance ENUM('low','normal','high') DEFAULT 'normal', relevance DECIMAL(4,3) NULL,
  district VARCHAR(60) NULL, cluster_id BIGINT UNSIGNED NULL, status ENUM('new','published','hidden') DEFAULT 'new'
);
CREATE TABLE news_clusters (id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, title VARCHAR(400), primary_item_id BIGINT UNSIGNED NULL, first_seen_at DATETIME NOT NULL);
CREATE TABLE news_actions (
  id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY, item_id BIGINT UNSIGNED NOT NULL,
  type ENUM('tariff_candidate','season_dates','window_review','rule_review','outage') NOT NULL, payload JSON,
  status ENUM('pending','applied','rejected') DEFAULT 'pending', reviewed_by INT UNSIGNED NULL, reviewed_at DATETIME NULL
);
CREATE TABLE user_news_prefs (
  user_id INT UNSIGNED PRIMARY KEY,
  categories SET('tariff','season','outage','methodology','verification','payments','water','electricity','contract') NULL,
  instant ENUM('off','high','all') DEFAULT 'high', digest ENUM('off','weekly') DEFAULT 'weekly'
);
```
