- **Полуповорот читается сам** (`web/ocr/engine.js`: `halfFix` → `drumCells`/`halfPair`): окно разбирается на ролики по светлому
  (полоса окна по высоте — где много тёмного; светлое = ярче окрестности, т.е. тень сверху не мешает; промежутки и кромки рамки
  прочь, размыкание 3×3; наклон ряда выправляется `cellSkew` и полоса перерисовывается). Ролик на переходе — два куска с пустой
  полосой (низ d сверху, верх d+1 снизу) или один кусок у края окна (`part`). Пара (d, d+1) — по шаблонам: цифры соседних роликов

## Как проверять
Локально: `SITE_BASE= SITE_DATA=/tmp/teplo_data php -S 127.0.0.1:8013 index.php`
(config.php в SITE_DATA: `'db' => ['dsn' => 'sqlite:/tmp/teplo_data/dev.sqlite'], 'cookie_secure' => false`).
Сборка: `python3 web/build.py`. Скриншоты с демо-данными: Playwright, `localStorage['teplo.v1']` = состояние
(пример — `places[0].water.meters` h1/c1, `S.water` записи, `readings`). Бой из сессии — Playwright с
`proxy:{server:process.env.HTTPS_PROXY}`, `ignoreHTTPSErrors:true`. Распознавание: `NODE_PATH=$(npm root -g) node tests/ocr-lab/run.cjs` (и `water_pair.json`). Узкие экраны: `tests/e2e/narrow.cjs`.
pkill по шаблону не использовать. Фото пользователей — не в репо (тесты только синтетика).
