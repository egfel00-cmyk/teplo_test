## 02.11.2026 (восьмая сессия) — «скільки це коштувало» без лічильника, правила и нормы (da203a9)
- **Тарифы без счётчика те же** — меняется только способ определить объём (Методика розподілу №315, ред. наказа №358 от
  28.12.2021): **повірка з демонтажем** (розд. I п. 5) — квартира НЕ считается без учёта, среднесуточное × сутки (тепло — за
  прошлый отопительный период, вода — за 12 мес до снятия); **поломка / заміна / прострочена повірка** (п. 4 пп. 3) — показания
  не принимают до следующего расчётного месяца после установки, считают как без учёта: тепло — доля дома по площади (ks = 1,
  точно не посчитать — только платёжка), вода — норма Харківводоканалу (28.12.2016) × прописанные.
- `TeploStats.gapHeat(g, ivs, {today, tariff})` → `{days, heatDays, avg, perMonth, gcal, cost, basis: prev|recent|none, season, rows[ym]}`;
  опалювальная сутки — если год назад в этот день тепло шло, без данных — 15.10…15.04; порог 0,003 Гкал/сут.
  `TeploWater.gapWater(g, recs, meter, {today, custom, persons, cfg})` → `{method: avg|norm, need: history|persons, m3, cost, vk, htm, rows}`;
  `NORMS` (6 строк для многоэтажек), `normOf(cfg)` (своя норма главнее). Тариф воды — на 1-е число месяца (смена 1.10 и 1.01).
- Форма периода (`gapView`): блок `#gp-est` «Скільки це коштувало» (`gapEstBox`) — правило, плитки (Гкал/м³, грн, в среднем
  на месяц), таблица по месяцам, «Розрахункових місяців», абонплата не входит, у горячей — Водоканал/ХТМ, сравнение с
  «Платили за місяць» (Гкал/міс по тарифу, грн/м² при заданной площади). Пересчёт на лету (`gapEstRefresh`, без перерисовки).
  Способ по причине (`gapPayDefault`: verify → avg, иначе area/norm), выбранный вручную (`data-touched`) не перебивается.
  Строка истории и `gapNote` в статистике — «≈ … грн за оцінкою», если сумма не указана.
- Настройки: Опалення → `nometerHeatPanel` (правила, `place.area`); Вода → `nometerWaterPanel` (`water.persons`, `normRow`,

## Как проверять
Локально: `SITE_BASE= SITE_DATA=/tmp/teplo_data php -S 127.0.0.1:8013 index.php`
(config.php в SITE_DATA: `'db' => ['dsn' => 'sqlite:/tmp/teplo_data/dev.sqlite'], 'cookie_secure' => false`).
Сборка: `python3 web/build.py`. Скриншоты с демо-данными: Playwright, `localStorage['teplo.v1']` = состояние
(пример — `places[0].water.meters` h1/c1, `S.water` записи, `readings`). Бой из сессии — Playwright с
`proxy:{server:process.env.HTTPS_PROXY}`, `ignoreHTTPSErrors:true`. Распознавание: `NODE_PATH=$(npm root -g) node tests/ocr-lab/run.cjs` (и `water_pair.json`); живые фото — `IMG_DIR=… node heat.cjs real_heat.local.json`. Узкие экраны: `tests/e2e/narrow.cjs`.
pkill по шаблону не использовать (убивает свою же оболочку — локальный php -S гасить по pid). Фото пользователей — не в репо (тесты только синтетика).
