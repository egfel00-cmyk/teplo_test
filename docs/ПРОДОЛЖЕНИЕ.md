## Как проверять
Локально: `SITE_BASE= SITE_DATA=/tmp/teplo_data php -S 127.0.0.1:8013 index.php`
(config.php в SITE_DATA: `'db' => ['dsn' => 'sqlite:/tmp/teplo_data/dev.sqlite'], 'cookie_secure' => false`).
Сборка: `python3 web/build.py`. Скриншоты с демо-данными: Playwright, `localStorage['teplo.v1']` = состояние
(пример — `places[0].water.meters` h1/c1, `S.water` записи, `readings`). Бой из сессии — Playwright с
`proxy:{server:process.env.HTTPS_PROXY}`, `ignoreHTTPSErrors:true`. Распознавание: `NODE_PATH=$(npm root -g) node tests/ocr-lab/run.cjs` (и `water_pair.json`); живые фото — `IMG_DIR=… node heat.cjs real_heat.local.json`. Узкие экраны: `tests/e2e/narrow.cjs`.
MariaDB для проверки схемы: `apt-get install -y mariadb-server`, `mysqld_safe &`, тесты сервера с DSN mysql (копия tests/server.php
с заменой `Db::set(new PDO('sqlite::memory:'…` на mysql). pkill по шаблону не использовать (убивает свою же оболочку — локальный php -S гасить по pid). Фото пользователей — не в репо (тесты только синтетика).
