## Открыто — по просьбе владельца 02.11 (в таком порядке)
1. **Вкладки «Історія / Статистика / Економія» — общие для всех счётчиков.** Сейчас они только про тепло, а история воды живёт
   внутри экрана воды — владельцу «нелогично». Сделать сверху переключатель `Опалення · Гаряча · Холодна` (вода — если есть
   водомеры; выбор в `S.view`, `data-act="view"`). Тепло — как сейчас. Вода: история (перенести список из `wwater()` —
   на экране воды оставить последние 3 + «Вся історія»), статистика (м³ по месяцам столбиками, среднее, стоимость по `Wt.cost`),
   економія (советы по воде + стоимость месяца).
2. **Вода «по фото, как отопление».** На `#wnew` (и «+» карточек воды) — большая кнопка «З фото»: пачка фото (оба водомера
   на одном или по фото на каждый) → `TeploOCR.read` → `Wt.fromOcr` → раскладка по водомерам: заводской № в строках
   (`meter.serial`), затем `drums[0].tint` ('red' — горячая, 'blue' — холодная; на КСМ/MASTER определилось верно),
   затем близость к прошлым (≥ прошлого, ближе всего). Миниатюры у полей, лайтбокс. Хорошо бы, чтобы `read` возвращал
   ВСЕ окна (сейчас останавливается на первом уверенном) — для фото с двумя счётчиками.
3. **Фото в истории** (и тепло, и вода): при каждом сохранении показаний — фото, с которых сняты, видны в записи истории.
   Сервер: `photos` + колонка `keep` (ALTER … ADD COLUMN IF NOT EXISTS), `cleanup` не трогает keep=1; `GET /api/photo?id=`
   (только владельцу, байты), `POST /api/photo/keep {ids}`. Клиент: `rec.photos=[{id, meter?}]` (синхронизируется в state);
   без входа — блобы в IndexedDB (`teplo-hist`, id `l:…`), после входа — догрузить. В истории — миниатюры → лайтбокс.
4. **Фото воды через Telegram-бота**: `bot_inbox` сейчас открывает только тепловой разбор — по `res.drums`/`meterType==='water'`
   направлять в водный.
5. **Напоминания** через бота (`cron.php`): вода — 15-го и 19-го, если нет записи воды в этом месяце; тепло — 5-го (окно ХТМ
   открылось) и 22-го, если нет показаний в окне. Таблица `reminders_sent(user_id, kind, ym)`; включатель в настройках.
6. Барабан: фото двух счётчиков издалека (блик на ведущих нулях) — дотянуть окно влево на недостающие ролики; `read` → все окна.
7. Не проверено на живом iPhone: клавиатура в шагах ввода, нижние табы. Экран «E-------» у теплосчётчиков.

## Как проверять
Локально: `SITE_BASE= SITE_DATA=/tmp/teplo_data php -S 127.0.0.1:8013 index.php`
(config.php в SITE_DATA: `'db' => ['dsn' => 'sqlite:/tmp/teplo_data/dev.sqlite'], 'cookie_secure' => false`).
Сборка: `python3 web/build.py`. Скриншоты с демо-данными: Playwright, `localStorage['teplo.v1']` = состояние
(пример — `places[0].water.meters` h1/c1, `S.water` записи, `readings`). Бой из сессии — Playwright с
`proxy:{server:process.env.HTTPS_PROXY}`, `ignoreHTTPSErrors:true`. Распознавание: `NODE_PATH=$(npm root -g) node tests/ocr-lab/run.cjs`.
pkill по шаблону не использовать. Фото пользователей — не в репо (тесты только синтетика).
