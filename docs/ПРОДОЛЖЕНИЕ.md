## Что есть (проверено на бою)
- Вход e-mail/пароль и Telegram (@heatcount_bot, Mini App), привязка через бота; несколько квартир (`S.places`).
- Главная: 3 карточки — Опалення / Гаряча / Холодна вода, у каждой «+» (сразу ввод). Отопление — маршрут `#heat`
  (бывший home), вода — `#water-hot`, `#water-cold`, ввод `#wnew`, мастер `#wsetup`, первый вход `#start`.
- Вода (`web/src/water.js` = TeploWater, данные `S.water` {meters, recs, acc, sn}, синк в sync.js):
  тарифы Водоканала с 01.10.2026 (49,446 + 20,820) и с 01.01.2027 (57,504 + 27,992), горячая ХТМ 86,32;
  проверки (дробь, меньше, без изменений, скачок >25 м³/мес, горячая>холодная); команда для бота Водоканала
  `@hvk_user_bot` `/2=СЧЁТ:Фамилия|ID-знач,…` (копировать → открыть → «передано»); горячая — ещё панель ХТМ; срок до 20-го.
- Фото: в браузере (PaddleOCR, `web/ocr/engine.js` v=6, тайлы 1408, ZOOM 2600), разбор `ocrparse.js` + `batch()` по времени
  съёмки и порядку экранов модели. Сохранение распознанных фото после перезагрузки (localStorage+IndexedDB), лайтбокс с зумом.
  Фото в Telegram-бота → входящие (`bot_inbox`) → открыть по кнопке `?inbox=1`.
- Счёт как в платёжке ХТМ: абонплата 29,40 + МЗК (ЗБП) — `costOf()` в app.js, настройки «Рахунок».
- Авто-перезагрузка при новой сборке (TEPLO_BUILD). Справка аккордеонами, политика/условия в футере настроек.
- Доступность: axe WCAG 2.1 AA + своя проверка рамок 3:1 — 0 нарушений в обеих темах (скрипт /tmp/axe.cjs — локальный, пропадает).
- Тесты: `php tests/server.php` (94), node tests/*.test.js: ocrparse 37, rules 33, sync 12, stats 10, places 3, water 21.

## Как проверять
Локально: `SITE_BASE= SITE_DATA=/tmp/teplo_data php -S 127.0.0.1:8013 index.php`
(config.php в SITE_DATA: `'db' => ['dsn' => 'sqlite:/tmp/teplo_data/dev.sqlite'], 'cookie_secure' => false`).
Сборка: `python3 web/build.py`. Бой из сессии — Playwright с `proxy:{server:process.env.HTTPS_PROXY}`, `ignoreHTTPSErrors:true`.
pkill по шаблону не использовать. Фото пользователей — не в репо (тесты только синтетика).
