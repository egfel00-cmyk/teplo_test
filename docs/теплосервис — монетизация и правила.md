# Теплосервис — монетизация и правила пользования (v2, 01.11.2026)

Черновик. Цены — гипотезы; юридические пункты — к юристу и бухгалтеру.

## 1. Принцип
- **Бесплатно** — всё, без чего нельзя вовремя и правильно передать показания, **включая подтверждение «принято ХТМ»** и одно уведомление о сроке повирки.
- **Платно** — автоматизация и удобство поверх надёжной подачи: расписание и повторы, несколько квартир, мониторинг ошибок, учёт повирки, глубокая статистика, платёжки, документы.
- Ориентиры цены: абонплата ХТМ ≈ 29 грн/мес; ближайший независимый аналог Utility Meter Log — $9.99/год (без подачи поставщику). Подача у поставщиков бесплатна, банки зарабатывают комиссией → продаём не саму подачу, а надёжность и удобство.
- Без рекламы.

## 3. Харьков и война
- **Блэкауты:** показания в Telegram уходят, когда появится связь; сайт ХТМ лежит → повторы до конца окна; NAS на EcoFlow, план на долгий простой.
- **Уехавшие собственники** — тариф «Власник»: арендатор/сосед снимает по ссылке, владелец отправляет.
- **Перебои с теплом** — кнопка «нет отопления» + данные счётчика → журнал (данные и шаблон, без юр. оценки).
- **Социальное:** «підвішена підписка» (подарок конкретному человеку или в фонд, заявка без документов); базовый тариф бесплатный навсегда.

## 4. Другие источники дохода

## 6. Правила пользования (документы, uk + ru, версии, учёт согласий)
1. **Публічна оферта / Умови користування** (электронный договор, Закон «Про електронну комерцію»).
2. **Політика конфіденційності**: данные (email, Telegram ID, адрес/квартира, лицевой счёт, фамилия, **логин и пароль к кабинету ХТМ — зашифрованы, показываются только владельцу**, показания, фото, платёжки, свидетельства), цели, основания, хранение (свой сервер в Украине; копии вне Украины — указать), сроки, получатели (ХТМ по поручению, Telegram, почта, платёжный провайдер, партнёр — только с разрешения), права, контакт.
3. **Згода на обробку персональних даних** (Закон № 2297-VI; писать по GDPR-подобным принципам — новый закон в процессе).
4. **Доручення на дії в кабінеті ХТМ** — «доручаю сервісу від мого імені входити до мого особистого кабінету КП «ХТМ» виключно для передачі показань і перевірки їх прийняття»; отзыв в один клик.
5. **Застереження:** независимый сервис, не связан с КП «ХТМ», не официальный канал, без логотипов ХТМ (урок неофициальных «городских» приложений с рейтингом 2,3–2,5★ и отзывами «не имеет отношения к поставщику»); расчёт — оценка; ответственность за показания — пользователь.
6. **Оплата и возвраты** (гривны, ФОП без НДС, автопродление, возврат, Stars).
7. **Форс-мажор (война):** блэкауты, атаки, недоступность ХТМ; по вине сервиса не работал в окно — продление подписки; о сбоях — всегда уведомление.
8. Реквизиты ФОП. 9. Cookies — только необходимые. 10. 18+ для платных тарифов.

**Риск автоматического входа:** правила сайта ХТМ неизвестны; Газмережі публично призывают не передавать данные третьим лицам. Делаем только порученное, редко и аккуратно; капчу не обходим; предложить ХТМ партнёрство/официальный канал до обновления их сайта.

## 7. Таблицы
```sql
CREATE TABLE plans (
  code VARCHAR(20) PRIMARY KEY, title_uk VARCHAR(80), title_ru VARCHAR(80),
  price_uah_month DECIMAL(8,2) NULL, price_uah_season DECIMAL(8,2) NULL, price_uah_year DECIMAL(8,2) NULL,
  price_stars_month INT NULL, price_stars_season INT NULL,
  limits JSON, features JSON, active TINYINT(1) DEFAULT 1
);
CREATE TABLE subscriptions (
  id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY, user_id INT UNSIGNED NOT NULL, plan_code VARCHAR(20) NOT NULL,
  period ENUM('month','season','year','lifetime') NOT NULL,
  status ENUM('trial','active','past_due','canceled','expired') NOT NULL,
  starts_at DATETIME NOT NULL, ends_at DATETIME NULL, auto_renew TINYINT(1) DEFAULT 1,
  provider ENUM('liqpay','wayforpay','mono','stars','gift','promo','manual') NOT NULL, provider_ref VARCHAR(120) NULL
);
CREATE TABLE payments (
  id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY, user_id INT UNSIGNED NOT NULL, subscription_id INT UNSIGNED NULL,
  provider ENUM('liqpay','wayforpay','mono','stars','iban') NOT NULL,
  amount DECIMAL(10,2) NOT NULL, currency ENUM('UAH','XTR') NOT NULL,
  status ENUM('pending','paid','failed','refunded') NOT NULL, fiscal_receipt_id VARCHAR(80) NULL, raw JSON, created_at DATETIME NOT NULL
);
CREATE TABLE gift_codes (
  code CHAR(12) PRIMARY KEY, plan_code VARCHAR(20) NOT NULL, period ENUM('month','season','year') NOT NULL,
  buyer_user_id INT UNSIGNED NULL, pool TINYINT(1) DEFAULT 0, redeemed_by INT UNSIGNED NULL, redeemed_at DATETIME NULL, expires_at DATETIME NULL
);
CREATE TABLE legal_documents (
  id INT UNSIGNED AUTO_INCREMENT PRIMARY KEY,
  type ENUM('terms','privacy','pd_consent','htm_mandate','refunds','disclaimer') NOT NULL,
  version VARCHAR(10) NOT NULL, lang ENUM('uk','ru') NOT NULL, body_md MEDIUMTEXT NOT NULL,
  published_at DATETIME NOT NULL, UNIQUE (type, version, lang)
);
CREATE TABLE consents (
  id BIGINT UNSIGNED AUTO_INCREMENT PRIMARY KEY, user_id INT UNSIGNED NOT NULL, document_id INT UNSIGNED NOT NULL,
  accepted_at DATETIME NOT NULL, channel ENUM('web','telegram','miniapp') NOT NULL, ip VARCHAR(45) NULL, revoked_at DATETIME NULL
);
-- partners, user_partner — «партнёры и ОСББ»
```
Права — одна проверка `can($user, 'auto_submit')` по подписке и `plans.features`; лимиты — `plans.limits`.

## 8. Проверить до запуска платных функций
- [ ] Бухгалтер: группа ФОП, КВЭД, ПРРО, доход в Stars/TON.
- [ ] Юрист: оферта, политика, согласие, доручення, возвраты.
- [ ] Эквайринг (рекуррент, комиссии); курс Stars.
- [ ] Название и домен без «ХТМ».
- [ ] Опрос 10–20 соседей и клиентов OTOS.
