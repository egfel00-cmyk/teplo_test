# Справочник областей «Лічильників» — как добавлять области и громады

Цель: человек вводит адрес квартиры — приложение само знает, кто в этой громаде поставляет свет, газ, воду и тепло,
по какой цене, **как и когда передавать показания** (кабинет, бот, сайт, телефоны) и куда платить. Неизвестное — честно
«впишіть з платіжки», а не выдумка. Готово: Харьковская (56 громад, наполнена с 25-й по 30-ю сессию), г. Киев, Киевская,
Одесская, Львовская (57-я: КАТОТТГ всех громад, областной уровень, центры), Хмельницкая (`km`, 99-я: КАТОТТГ, областной уровень,
Хмельницька громада; 100-я: ещё 8 громад по населению). Дальше — громады Хмельниччины по населению.

## Где что лежит
- `tools_katottg.py` — КАТОТТГ (github.com/suprun/katottg.json, MIT) → `app/data/<r>_katottg.json`. `REGIONS` (код рівня 1),
  `OLD` (рус./старые названия крупных пунктов), `H_NEW` (громады, переименованные позже КАТОТТГ). Запуск:
  `python3 -I tools_katottg.py <katottg.json> <archive/KATOTTG-2024-10-01/katottg.json>` (второй — для переименований).
- `app/providers.php`: `Providers::REGIONS` и `OBL_RE` (как область пишут в адресе) — добавить регион сюда тоже.
  `kh` — в `app/data/providers.json` (вместе с `national`), остальные — `app/data/prov_<r>.json`.
- Уровни: `oblast` (вся область) ← `hromadas["<ключ>"]` ← `settlements["<ключ>/<пункт>"]`. Ключ громады — её название из КАТОТТГ;
  одинаковые в области — «Назва (центр)» или «Назва (район р-н)» (`kat.hromadas[id].k`, `Providers::hkey`). Вода и тепло громады
  заменяют областное целиком; у пункта другой `org` — от громады ничего не берём.
- Правки владельца из /admin → «Справочник» лежат на сервере поверх репозитория (`ProvEdit`, `SITE_DATA/uploads/settings/prov_edit.json`).
  `/api/health → prov.edits` > 0 — **первым делом перенести их в репозиторий** (см. ниже); `ProvEdit::prune` (cron, :17) потом сам
  уберёт правки, совпавшие с репозиторием.

## Формат вида (поля — только эти, `ProvEdit::clean`)
- Все: `org` (null — не знаем), `how`/`how_ru` (как и когда передавать — простыми словами, сроки), `cab`, `bot`, `site`, `app`
  (только `https://`), `phones` `[[tel, как показать, подпись]]`, `pay`/`pay_ru`, `note`/`note_ru` (подсказка людям), `src`/`src_ru`
  (решение, №, дата, сайт), `check: true` (не уверены — «звірте з платіжкою»), `robot` + `robot_note` (см. «Без человека»).
- Вода: `supply`, `drain` (водоотведение отдельно!), `hot` (ГВ, грн/м³), `from`. Тепло: `price` (грн/Гкал), `abon`, `from`.
  Тепло не от ХТМ (126-я): приложение просит **одно число — энергию** (как на экране), без формы и правил ХТМ; `how` — что передавать и
  до какого числа (нет `how` — общий текст «одне число… повірений, опломбований, на обліку»), `till` — число месяца, до которого передают
  (31 — до конца месяца; есть — напоминание за 4 дня, нет — без срока). Киев: `till: 31` (с 5-го до конца месяца).
- **Окно приёма показаний `win`** (136-я, 137-я; вода и тепло, не вывоз): `[A, B]` — числа месяца, только из явного «з A по B число» на сайте КП/громады
  или в `how`; «до N числа» без начала — **не вписывать** (полоски нет). B < A — через конец месяца (20–4), B = 31 — до конца месяца, A = 31 — с последнего дня
  (Хмельницький 31–3). **B = −1 / −2 — последний / предпоследний РАБОЧИЙ день** (пн–пт; Львівводоканал `[10, -2]`, Вишгород `[25, -2]`, Фастів `[25, -1]`);
  в /admin это «10–пр», «25–р». Есть `win` — впиши то же окно в `how`/`how_ru` словами. Разные окна у каналов одного КП (Київ: ЦКС с 5-го, Київводоканал с 10-го) —
  без `win`. Тест: `tests/server.php` «усі win валідні».
  **Где искать окно (138-я) — п. 22 типового индивидуального договора КП** (КМУ № 690; раздел «Облік послуги»): «У разі коли зняття показань здійснює споживач,
  він щомісяця з __ по __ число передає показання…» — КП вписывает свои числа (Пісочин 20–27, Зміїв 25–31, Буча 25–30, Обухів 20–25, Славута 25–30, Славутич 22–28, Деражня 25–30 — «щомісяця з 25 по 30 надає інформацію про обсяги», без «показ»). Договор лежит
  на сайте КП («Документи», «Договори», «Публічна оферта», «Індивідуальний договір»); там же в «Реквізитах» — e-mail и телефон для показаний (Славута: otbanka@i.ua → бот `slv`).
  Старые договоры (КМУ № 630, до 2021) — срок «не пізніше останнього дня місяця» (Люботин п. 17), «не пізніше 28 числа» (Кам’янець) — это «до N», `win` не ставим.
  Как читать в Chrome владельца: HTML — `document.body.innerText` и поиск `він\s+щомісяця`; **.docx того же сайта** — `fetch` в странице сайта + разбор zip в JS
  (центральный каталог → `word/document.xml` → `DecompressionStream('deflate-raw')` → снять теги); **Google Docs** — открыть `/document/d/<id>/edit`, затем
  `fetch('/document/d/<id>/export?format=txt')`; **PDF с текстом** (139-я) — в странице сайта `await import('https://cdn.jsdelivr.net/npm/pdfjs-dist@4.0.379/build/pdf.min.mjs')`, `getDocument(путь того же origin)` →
  `getTextContent()` по страницам → поиск `щомісяця з` (так Подільськ 25–1; у info-gkh.com.ua — «Публічний договір»: бланк с пропусками и рядом заполненный `…-tipoviy-indiv-dog.pdf`;
  чужие поддомены info-gkh — CORS, открывать каждый сайт); скан — встроенный просмотрщик: миниатюра страницы 3–4 → `zoom` (п. 22 обычно там); в ответе javascript_tool
  не выводить значения скрытых полей и `?query` (фильтр «Cookie/query string data» режет весь ответ — в выводе и `?`, `&`, `=` заменять пробелом). rada.info из Chrome читается (139–140-я): .doc — `fetch` того же origin (UTF-16), PDF — `navigate` на сам PDF и pdf.js (Ізяслав-тепло 25–30). Сайт за проверкой Cloudflare («Один момент…», teplo.km.ua) — не проходим, пропускаем. Тепло тоже по КМУ № 830: п. 23 «з __ по __» (Шепетівка — бланк пустой), в договоре тепла часто и e-mail для показаний (Ізяслав iz_teplo@ukr.net, Броварі tepl0@ukr.net, Шепетівка shepetivka_ptm@ukr.net) → почтовый робот с `kinds: ['heat']`; общий ящик большого предприятия, которого нет в «контакти для передачі показань» (Київтеплоенерго info@kte…, Львівтеплоенерго office_lte@…), — не берём. Сканы с «мусорным» текстовым слоем (Броварі 2021) — читать глазами в просмотрщике (End / миниатюра нужной страницы, `zoom` на реквизиты). У тепла рядом с `win` ставить `till` = конец окна (напоминание).
  Свет: `net` (ОСР). Газ: `grm` (оператор ГРМ — кому показания), `dist`, `distFrom`, `distSrc`. `org` газа — поставщик (Нафтогаз).
  Вивіз сміття (`waste`, 112-я): `price` — грн **з людини на місяць** (багатоквартирні), `priv` — приватний сектор (если другая), `abon` — абонплата **за особовий рахунок** на месяц, если отдельно от «з людини» (116-я, Балаклія 10,01: к сумме добавляется один раз), `from`, `pay`, `phones`, `site`;
  уровни — как у воды (громада заменяет область, пункт со своим `org` — без громады). «Намір» КП без решения — цена + `check` + `note` «рішення не знайшли».
- Будущий утверждённый тариф — `next: {from, supply, drain|price}` (или список): с даты сервер подставит сам.
- `via: hvk|htm` — только Харьков (там свои роботы). Тариф без `src` и `src_ru` — тест падает.
- Газ: `grm`, начинающийся с «Газмережі», — общие каналы Газмереж (бот, my.grmu, «Куб», SMS 4647 до 28.11.2026); иной оператор
  (Київгаз, Одесагаз) и любой свет вне Харьковщины — в «Куди передати» блок местного поставщика из `how/cab/bot/site/phones`.

## Порядок наполнения области
1. **КАТОТТГ**: `REGIONS` в tools + `Providers::REGIONS`/`OBL_RE`; `OLD` — рус. и старые названия городов (декомунізація 2016 и 2024:
   Червоноград → Шептицький, Южне → Південне, Котовськ → Подільськ…). Проверить: `Providers::lookup('<рус. название>, <ул.>')`.
2. **Областной уровень** (`oblast`): свет — постачальник універсальних послуг + ОСР, окно показаний, каналы, телефоны; газ — оператор ГРМ
   и тариф доставки (index.minfin.com.ua → «Тарифи на газ … області», дата «з 1.<місяць>»); вода и тепло — «впишіть з платіжки».
3. **Громады по приоритету**: областной центр → города по населению → то, что ищут люди (/admin → «Справочник» → «Что ищут люди»;
   сверху — где нет воды или её тарифа). Каждой: вода (КП/ТОВ, тариф для **населения**, водоотведение, дата, решение), тепло (если
   центральное), сроки и каналы показаний, телефоны, куда платить. Сёла со своим КП — `settlements`.
4. **Тесты**: `tests/server.php` (несколько адресов региона: название, рус. название, старое, тарифы); `tests/e2e/e2e_prov.cjs` — регион
   на экране квартиры и «Куди передати»; общий тест «громады и пункты есть в КАТОТТГ, у тарифов src» уже проверяет все регионы.
5. Пуш, бой (`/api/health → prov.regions.<r>.w` — сколько громад с водой), ПРОДОЛЖЕНИЕ: что сделано и **список оставшихся громад**.

## Как искать (что работало)
- WebSearch с `allowed_domains: ["gov.ua"]` + название КП или громады (`*-gromada.gov.ua`, `*-rada.gov.ua`, `kyivcity.gov.ua`);
  без фильтра тонет в общих новостях. Названия КП — prozorro, старые справки ОДА о тарифах, ЄДРПОУ.
- Свежие суммы по крупным городам — dengi.ua / minfin / сайты КП; всегда до первоисточника (решение виконкому/МВА, №, дата).
- WebFetch открывает только адреса из выдачи поиска или от владельца (иначе «Nobody answered») — сначала найти страницу поиском.
- **Ловушки** (стоили сессий на Харьковщине): одинаковые громады в разных областях (kammiskrada.gov.ua — Кам’янка Черкаської, а не Кам’янка-Бузька (kbmr.gov.ua); zlmr.gov.ua — Золочів Львівської, а не
  86-я: zolochivska-gromada.gov.ua («Феськівське ЖКГ») — Золочівська **Харківщини**; Золочівська Бориспільського р-ну Київщини — zolochivskarada.gov.ua. Київщина заполнена (69/69) — тест /admin «громада без воды» теперь на Липецькій (`kh`).
  Харківської; Новопокровська — Дніпропетровщини) — сверять индекс и район; «намір змінити тариф» ≠ решение; тариф для бюджета/інших
  ≠ для населення; PDF-скан — суммы не читаются, `null` + `note`; тепло населения под мораторием (старая цена действует);
  абонплата отдельно; водоотведение часто отдельным решением.
- Нет данных — `org` и тариф `null`, `note` честно «з платіжки», `src` — где искали. Не брать цифры из «середніх по Україні».
- **Львівщина — портал відкритих даних data.loda.gov.ua** (63-я): ~70 громад сами публикуют набор «Дані про тарифи на комунальні послуги»
  (поля `type`, `consumersType`, `unitAmountValue`, `providerName`, `validFrom`, `legalActNumber`, `legalActIssued`, `legalActUrl`) — с номером
  и датой решения. Из облака сессии CSV не открыть (прокси, WebFetch просит одобрения) → **встроенный браузер владельца**: открыть любую страницу
  портала и в `javascript_tool` — CKAN API того же origin: `/api/3/action/package_search?q=тарифи комунальні послуги&rows=400` →
  у ресурсов с `datastore_active` — `/api/3/action/datastore_search?resource_id=…&limit=2000`, остальные — `fetch(res.url)` (бывают UTF-16LE и cp1251).
  Качество разное: часть громад без сумм (null), категории пустые (2–3 цены — для населения обычно нижняя, `check`), опечатки в датах.
  Сверка: сумма «вода + стоки» должна сойтись с обзором соседей (Борислав 51,60 + 24,07 = 75,67 из обзора Дрогобича).
  Ловушка: **МКП «Миколаївводоканал»** есть и у Миколаєва Львівської (mykolaivmr.gov.ua), и у міста Миколаїв — брать с портала Львівщини.
- Вложения решений на rada.info (.doc/.docx) из облака не скачать, а браузером — CORS (`www.rada.info` ≠ `rada.info`; `rada.info/*` редиректит на www, а файлы там 404).
  **Обход (64-я)**: во встроенном браузере открыть `https://view.officeapps.live.com/op/view.aspx?src=<encodeURIComponent(url вложения)>` — **xlsx** читается
  (текста в DOM нет — скриншот; к ячейке — клик в поле адреса ячейки, `A1`, Enter; листы — вкладки внизу). Так взяли Кілію (додаток рішення № 63). **docx** этот viewer показывал пустым.
  Не вышло — `null` + note с № решения.
- Портал Львівщини: часть CSV в **cp1251** (в datastore — «кракозябры» вида `Öåíòðàë³çîâàíå`) — брать `resource_show → url` и декодировать `TextDecoder('windows-1251')`;
  у части громад datastore пустой (0 записей) при живом CSV (Красне, Славське); даты бывают m/d/y (Івано-Франкове) и числом Excel (44396 = 19.07.2021, Підберізці).
  Без набора тарифов на портале (64-я): Щирецька, Сокільницька, Солонківська, Мурованська, Куликівська, Боринська, Заболотцівська, Добросинсько-Магерівська,
  Бісковицька, Стрілківська, Гніздичівська, Шегинівська, Козівська — в наборах только ТПВ/прибирання. **Ловушка**: kulykivska-gromada.gov.ua — Куликівка **Чернігівщини**, не Куликів Львівщини.

- **Сайты громад на gromada.org.ua** (`*-gromada.gov.ua`, `*-rada.gov.ua`; 65-я) — во встроенном браузере, fetch того же origin: `/sitemap/` (все страницы, искать «тариф|водопост|КП»)
  и `/search/?q=` (страницы, где слово в тексте — списки рішень виконкому по годам). Решения — на rada.info: PDF и jpg открываются прямо (страница PDF — `#page=N&zoom=130`),
  .doc — через Office viewer (`view.officeapps.live.com/op/view.aspx?src=…`, читать скриншотом). Домен угадывать `fetch(url, {mode:'no-cors'})` — DNS-ошибка = нет сайта.
  Нет решений на сайте — поставщика ищи в prozorro (договоры «централізоване водопостачання» отдела образования/ради). Ловушки: kulykiv-gromada.gov.ua — Куликів Львівщини,
  kulykivska — Чернігівщина; kozivska-gromada.gov.ua — проверить область (Козова Тернопільщини?).

- **Вложения rada.info целиком (66-я)**: во встроенном браузере открыть любой файл того же origin (например картинку `https://rada.info/upload/users_files/<код>/<…>.jpg`),
  затем `fetch('/upload/users_files/<код>/<…>.docx')` того же origin (CORS не мешает) и распаковать `word/document.xml`: найти central directory zip, данные файла —
  `new Response(new Blob([data]).stream().pipeThrough(new DecompressionStream('deflate-raw'))).text()`, теги `</w:p>` → перевод строки. Так прочли Березівку № 08-134 (Office viewer docx не показывал).
- **Joomla-сайты рад** (tatarbunary.od.ua): поиск — `index.php?option=com_search&searchword=…&searchphrase=all&limit=50`; у Татарбунар есть страница открытых данных
  «Дані про тарифи на комунальні послуги, які затверджуються органом місцевого самоврядування» — все решения по сёлам с № и датой одной таблицей.
- **PDF на Google Drive** (новости рад со ссылкой «drive.google.com/file/d/…/view»): скан, текста нет. Скриншоты встроенного браузера там «застывают» (окно перекрыто) —
  `computer` → `zoom` даёт свежий кадр; листать — в JS `scrollTop` у контейнера с самым большим `scrollHeight` (страницы ≈ 979 px).
- Сайт громады на gromada.org.ua может отдавать пустой ответ на `fetch('/search/?q=')` (Кілія) — тогда `navigate` на ту же страницу и читать DOM.
- Без тарифов (66-я, проверено): Гніздичівська, Козівська (Стрийський р-н — Львівщина, не Тернопільщина), Шегинівська, Боринська (сайта на gov.ua нет), Добросинсько-Магерівська.
