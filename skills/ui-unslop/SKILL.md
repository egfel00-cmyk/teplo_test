# Дизайн «Лічильників» без шаблонности — аудит и правка

Основа — скилл **unslop** Дамира Соколовского ([@heydamir](https://x.com/heydamir), github.com/heydamir/unslop, CC BY 4.0;
адаптировано и сокращено для этого проекта, 83-я сессия, 09.11.2026), линза **frontend-design** и наш брендбук
(`design/02-brandbook.md`, `design/03-design-system.md`). Где правила расходятся — главнее наше: аудитория 45+ и пенсионеры.

**Когда:** новый экран или блок; правка лендинга; владелец пишет «некрасиво / как у всех / нейросетевое»; раз в несколько сессий —
полный обход. **Проверка в CI-стиле:** `python3 tests/design_lint.py` (перед пушем, рядом с `php tests/server.php`).

## Направление (не менять без владельца)
- **Продукт** — показания тепла, воды, света и газа: подсказываем, куда и до какого числа передать, проверяем как робот ХТМ.
- **Характер** — спокойный, точный, заботливый.
- **Мир** — корпус квартирного прибора: серо-зелёный пластик, ЖК-экран, ролики водомера, трубы подачи (красная) и обратки (синяя).
- **Моменты** — только **табло приборов** (ЖК тепла, ролики воды и газа, экран света). Всё вокруг — тихое.
- **Подпись** — табло повторяет ровно то, что человек видит на приборе (семисегментные цифры, ролики, метки Gcal / m³ / kWh).

## Порядок
1. **Посмотреть глазами.** Сайт локально, `tests/design/shots.cjs`: 390 и 1280, светлая и тёмная, демо `{"elec":true,"gas":true}`
   (+ `"second":true` для квартир). Лендинг целиком — с `RM=1` (иначе секции без анимации пустые на полном скрине). Длинное — `tile.py`.
2. **Аудит** по признакам ниже — строка на находку: где и что. `python3 tests/design_lint.py` ловит механику (жирность, капс, кривые, «!»).
3. **Объём.** Много признаков — полный проход; мало — только найденное, палитру и компоновку не трогать; чисто — сказать и не переделывать.
4. **Проходы по порядку**, каждый по всему экрану: отступы → цвет → значки → тексты → шрифт → компоновка → детали → картинки → движение.
5. **Проверка:** чек-лист, скрин заново (не больше трёх раз), `design_lint`, затронутые e2e, `narrow.cjs`.
6. **Отчёт владельцу** — коротко, что поменялось по проходам; в `design/06-ux-heuristics-audit.md` — таблица находок.

## Правила по проходам (наши числа)
1. **Отступы** — сетка 4 px (`--sp-1…7` = 4, 8, 12, 16, 24, 32, 48); шаг 2 px — только внутри мелких контролов и для точного центрирования.
   Одинаковое — одного размера (строки списка, отступы соседних карточек). Внутри группы меньше, чем между группами.
2. **Цвет** — нейтрали из брендбука (housing, surface, ink, ink-2, line); три роли текста (ink, ink-2, muted). Цвет несут табло, статусы
   (ok/warn/bad/info — всегда со словом и значком), **тона блоков** (решение владельца 07.11: «Куди передати» бирюзовый и т. д.) и цвет квартиры.
   Нельзя: переходы между оттенками, градиентный текст, цветные свечения и тени, пятна-«сияния», неоновые рамки. Градиент — только как
   материал табло (ролики, ЖК, жёлтая панель газа) или тон внутри одного нейтрального.
3. **Значки** — свои линейные SVG (`ico()`), 16/18/20/24, обводка 1.75; эмодзи в интерфейсе — нет. Цвет значка вида счётчика — цвет вида (брендбук).
4. **Тексты** — без «!», без приветствий, без хайпа («магія», «легко», «миттєво»); кнопка называет действие, тост повторяет то же слово.
   Короткие подписи, кнопки и заголовки — без точки в конце; предложения в подсказках и ошибках — с точкой. «→» — только как путь меню
   («Налаштування → Вода»), не в кнопках и ссылках. Отдельные пилюли и метки — с большой буквы (`ucf()`), внутри фразы — с малой.
   Мок-данные — правдоподобные, как в настоящем приложении.
5. **Шрифт** — IBM Plex Sans 400/500/600 (700+ нет), Plex Mono — только значения, которые копируют в кабинет ХТМ. Без капса и разрядки.
   Отрицательный трекинг — только крупные заголовки (≥ 24 px). `tabular-nums` для цифр в столбик. **Текст ≥ 15 px**, мета и подписи ≥ 13,
   нижняя навигация ≥ 11 — **мельче unslop’овских 12–14 не опускаемся** (пожилые).
6. **Компоновка** — разделы и их порядок не трогать. Одна главная кнопка и максимум одна вторичная рядом. Касание ≥ 48 px (unslop: 40–44 — у нас нет).
   Длинная подпись кнопки переносится по центру (`.btn`: `text-wrap: balance`).
7. **Детали** — вложенные радиусы: внутренний = внешний − отступ, не меньше 4 (поле 10, кнопка 12, карточка 14–16, панель лендинга 28–40).
   Наведение и фокус есть (кольцо 3 px). Карточки, которые не кнопки, при наведении **не поднимаются**. Графики: одна главная серия
   акцентом, остальное — нейтральные ступени; подписи осей приглушённые.
8. **Картинки** — декоративных пятен, сеток и «сфер» нет. Лендинг показывает продукт: телефон с настоящей главной и настоящие табло.
   Генерация изображений — только с согласия владельца (платно).
9. **Движение** — одна кривая `var(--ease)` = `cubic-bezier(.22, 1, .36, 1)`; 120–180 мс отклик, 160–220 меню, 300–500 появление.
   Анимируем только color, background, border, opacity, transform (исключение — тонкие полосы прогресса `width`).
   По кругу крутится **только живое**: идёт распознавание (`phd-*`), занятость (`spin`), мигающий светодиод «imp» (так мигает настоящий).
   Без параллакса, наклона за мышью, «дыхания», пульса, бликов, появления секций при прокрутке, пружин с перелётом.
   Одна появляющаяся анимация при входе на экран (`cardIn`) и «докрутка» роликов — ок. `prefers-reduced-motion` — всё статично.

## Признаки шаблонности (искать)
Фиолетово-синие и любые «оттенок → оттенок» заливки; градиентный текст; свечения; пятна за контентом; стеклянные карточки с цветной тенью;
пилюля-бейдж над заголовком (`✨ Новое…`); точка-пульс; кнопка с бликом и «→»; номера шагов в градиентных плашках; одинаковые карточки
рядом; капс-надзаголовки (`СЕРВІС`); 700–900 в заголовках; минус-трекинг на мелком; «!»; эмодзи вместо значков; `transition: all`;
бесконечные анимации; параллакс; «Усе, що потрібно, — під рукою» — заголовок, подходящий любому продукту (**проверка на шаблон**:
подставь чужое название — подходит? значит, переписать своими словами).

## Оставлено осознанно (не «чинить»)
Тона блоков и цвет квартиры (владелец); цвет значков видов; моно для значений ХТМ; метка «бета» (тестовый период); плавающая «Відгук»
(владелец, 01.11 — перекрывает «+» карточки при прокрутке, кандидат в шапку, если владелец согласится); пустая строка под полем
«Населений пункт» (место под ответ поиска — без прыжков разметки); градиенты-материалы табло; «·» между числами одной строки.
Лицьова панель приладу на лендингу (89-я, владелец «сделай презентабельнее»): герой и финальный призыв — `lp-plate` (литой графитово-зелёный пластик
одним тоном + светлое пятно «лампы» белым с прозрачностью, фактура литья, шов крышки, четыре винта `lp-screw`), окошки шагов — светлый пластик `lp-art-w`;
в линтере — материал, как ролики и ЖК. При входе на лендинг табло докручиваются один раз (`liveDigits`, reduced-motion — нет).
Лента постачальників на лендингу — бесконечная, справа налево, две строки (владелец 10.11: «пусть плывут»; `lpMarq` в линтере), на наведении пауза, при reduced-motion стоит.
